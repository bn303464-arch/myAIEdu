# 8주차 실습 가이드 — 내 경험으로 만드는 첫 서비스

> 결과물: 한 장 비즈니스 캔버스, 가격·손익분기 계산 결과, 소개 페이지 초안, 1분 발표 원고
> 소요 시간: 75분 · 7주차 결과물을 옆에 펼쳐 두고 시작한다.

## 시작 전 안전 수칙

- 고객사 이름, 거래 조건 등 전 직장의 영업 비밀은 AI에 넣지 않는다.
- AI가 말한 시장 규모, 통계, 정부 지원 정보는 **출처를 확인하기 전까지 사실로 쓰지 않는다**.

---

## 1단계. 아이디어 고르기 (15분)

### AI에게 아이디어 받기

```
[7주차 브랜드 한 문장]
위 경험을 바탕으로 혼자서, 큰 돈 들이지 않고, 한 달 안에 시험해 볼 수 있는
작은 서비스 아이디어 3개를 제안해 줘.
각 아이디어마다 고객, 형태(강의/대행/상담/템플릿/모임), 예상 가격대,
가장 큰 약점, 일주일 안에 해 볼 수 있는 검증 방법을 표로 정리해 줘.
```

### 하나 고르기 — 세 가지 질문

| 질문 | 아이디어 1 | 아이디어 2 | 아이디어 3 |
|---|---|---|---|
| 돈을 낼 사람을 3명 이상 떠올릴 수 있나? | | | |
| 다음 주에 바로 시작할 수 있나? | | | |
| 내가 하면서 즐거울까? | | | |

"예"가 가장 많은 것을 고른다.

## 2단계. AI와 캔버스 채우기 (20분)

### 방법 A — 예시 코드 사용

1. `examples/sample_idea.json`을 복사해 `my_idea.json`을 만들고 고른 아이디어로 채운다.
2. 실행한다.

   ```bash
   python curriculum/week08/examples/business_canvas.py --input my_idea.json
   ```

3. 출력된 **캔버스 요청문**을 AI에 붙여 넣는다. 함께 출력되는 **숫자 점검** 결과는 3단계에서 쓴다.

### 방법 B — 직접 쓰기

```
너는 4050 직장인의 첫 1인 사업을 돕는 창업 코치야.

[나에 대해] [7주차 브랜드 한 문장]
[아이디어] [고른 아이디어 한 줄]
[고객] [ ]
[가격] [ ]원

다음 일곱 칸으로 한 장 비즈니스 캔버스를 표로 채워 줘:
고객, 문제, 해결책, 차별점, 알리는 길, 가격, 비용.
그다음 이 아이디어의 가장 큰 위험 3가지와, 각각을 돈 들이지 않고 확인하는 방법을 알려 줘.
통계나 시장 규모를 쓸 때는 출처를 함께 적고, 확실하지 않으면 [확인 필요]로 표시해 줘.
```

### 대화를 이어가는 요청문

- "고객을 더 좁혀서 한 사람의 하루로 묘사해 줘."
- "이 가격이 비싸다고 느낄 고객에게 할 수 있는 말 3가지를 적어 줘."
- "알리는 길 중 비용이 0원인 것만 골라 줘."

## 3단계. 가격·손익분기 계산 (10분)

예시 코드를 썼다면 출력된 숫자를 확인하고, 아니면 아래 표를 계산기로 채운다.

| 항목 | 값 |
|---|---|
| 가격(한 건) | 원 |
| 한 건 비용 | 원 |
| 한 건 남는 돈 (가격 − 한 건 비용) | 원 |
| 월 고정비 | 원 |
| 손익분기 건수 (월 고정비 ÷ 한 건 남는 돈, 올림) | 건 |
| 월 목표 순수익 | 원 |
| 목표 건수 ((월 고정비 + 목표) ÷ 한 건 남는 돈, 올림) | 건 |

**점검**: 목표 건수를 한 달에 실제로 해낼 수 있는가? 어렵다면 가격을 올리거나, 비용을 줄이거나, 목표를 낮춘다.

## 4단계. 소개 페이지 만들기 (20분)

1. AI에게 소개 페이지 문구를 요청한다.

   ```
   위 캔버스로 한 장짜리 소개 페이지 문구를 써 줘.
   한 줄 제목(고객의 문제로 시작), 부제, 이런 분께 추천(3개), 얻게 되는 것(3개),
   진행 방식, 가격 안내, 신청 안내 문구 순서로. 과장 표현 없이 담백하게.
   ```

2. `examples/landing_page.html`을 브라우저로 열고, 다듬은 문구를 칸마다 붙여 넣는다.
3. 오른쪽(휴대폰은 아래) 미리보기를 확인하고 화면을 캡처한다.
   신청 연락처 칸에는 **실습 중에는 실제 번호 대신 "강의 후 안내"처럼 적는다**.

## 5단계. 1분 발표 준비 (10분)

아래 틀을 채워 소리 내어 두 번 연습한다.

```
안녕하세요, [7주차 명함 한 줄]인 저는
[고객]이 겪는 [문제]를 [해결책]으로 돕는 [서비스 이름]을 준비했습니다.
[가격]에 [얻게 되는 것]을 드립니다.
다음 한 달 동안 [첫 검증 계획]을 해 보려 합니다. 의견 부탁드립니다.
```

## 완료 기준

- [ ] 캔버스 일곱 칸이 채워져 있고, AI가 지어낸 숫자는 지웠거나 확인했다.
- [ ] 손익분기와 목표 건수를 계산했고, 한 달에 해낼 수 있는 수준으로 조정했다.
- [ ] 소개 페이지 화면을 캡처해 저장했다.
- [ ] 1분 발표를 했거나 강사에게 보여 주었다.
- [ ] 30일 실행 계획 카드를 작성했다.

## 자주 묻는 질문

**Q. 가격을 얼마로 해야 할지 모르겠어요.**
A. 비슷한 서비스 3개의 가격을 직접 찾아보고 그 가운데쯤에서 시작한다. AI에게 "비교 기준"을 묻는 것은 좋지만, 가격 자체는 직접 확인한 자료로 정한다.

**Q. 사업자 등록을 해야 하나요?**
A. 형태와 소득 규모에 따라 다르다. 첫 검증 단계에서는 지인 대상 소규모 시험으로 시작하고, 지속할 계획이 생기면 세무서나 창업지원센터에 상담한다.

**Q. 실패하면 어떡하죠?**
A. 8주차의 목표는 성공이 아니라 **첫 반응을 보는 것**이다. "아무도 사지 않았다"도 소중한 결과이며, 고객이나 가격을 바꿔 다시 시험하면 된다.
