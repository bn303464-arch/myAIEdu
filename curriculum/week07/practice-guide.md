# 7주차 실습 가이드 — 나만의 프로필 카드 만들기

> 결과물: 브랜드 한 문장, 키워드 3개, 자기소개 3종(30초 · 온라인 프로필 · 명함 한 줄)을 담은 프로필 카드
> 소요 시간: 60분

## 시작 전 안전 수칙

- 실명, 전화번호, 주소, 전 직장의 내부 정보는 AI에 넣지 않는다. "저", "제조업 중견기업"처럼 바꿔 쓴다.
- AI 답변의 숫자와 사실은 **반드시 내가 확인**한다. 내가 주지 않은 내용은 지운다.

---

## 1단계. 경력 재료 정리 (15분)

아래 표를 종이나 메모장에 채운다. 완벽하지 않아도 된다.

| 항목 | 내 답 |
|---|---|
| 하는 일(직무·업종) | |
| 경력 기간 | |
| 가장 자신 있는 일 3가지 | |
| 숫자로 말할 수 있는 성과 2~3개 | |
| 내 도움이 필요한 사람(대상) | |
| 그 사람이 겪는 문제 | |
| 나만의 방식 | |
| 원하는 말투 | 예: 존댓말, 담백하고 따뜻하게 |
| 쓰고 싶지 않은 표현 | 예: 최고, 혁신, 1등 |

**막힐 때 AI에게 묻는 요청문**

```
나는 [업종]에서 [기간] 동안 [직무]를 해 왔어.
내 강점을 찾을 수 있도록 질문을 5개만 하나씩 해 줘. 답을 들은 뒤 다음 질문을 해 줘.
```

## 2단계. 요청문 만들기와 AI 대화 (20분)

### 방법 A — 예시 코드 사용 (컴퓨터 실습실)

1. `examples/sample_profile.json`을 복사해 `my_profile.json`을 만들고 1단계 내용을 채운다.
2. 터미널에서 실행한다.

   ```bash
   python curriculum/week07/examples/brand_profile.py --input my_profile.json
   ```

3. 화면에 나온 **브랜드 한 문장 초안**을 확인하고, **AI 요청문** 전체를 복사해 AI 서비스에 붙여 넣는다.

### 방법 B — 직접 쓰기 (스마트폰)

아래 틀의 [ ]를 채워 AI에게 보낸다.

```
너는 4050 경력자의 전직과 1인 사업을 돕는 커리어 코치야.

[내 재료]
- 하는 일: [ ]
- 경력: [ ]년
- 강점: [ ], [ ], [ ]
- 성과: [ ]
- 도움을 줄 대상: [ ]
- 그 대상의 문제: [ ]
- 나만의 방식: [ ]

[만들어 줄 것]
1. 브랜드 한 문장 (나는 ~를 위해 ~를 ~로 해결하는 ~이다)
2. 키워드 3개
3. 30초 자기소개 (말로 하기 좋게, 150자 안팎)
4. 온라인 프로필 소개 (300자 이내)
5. 명함 한 줄 (25자 이내)

[조건]
- 말투: [ ]
- 다음 표현은 쓰지 마: [ ]
- 내가 준 정보에 없는 사실은 만들지 말고, 추측한 부분은 [확인 필요]로 표시해 줘.
```

### 대화를 이어가는 요청문

- "3번을 더 짧고 구어체로 바꿔 줘."
- "대상을 [다른 대상]으로 바꾸면 1번이 어떻게 달라질까?"
- "세 가지 버전을 표로 비교해 줘."

## 3단계. 사실 확인과 말투 다듬기 (15분)

1. AI 답변에서 **[확인 필요]** 표시와, 내가 주지 않은 숫자·이름에 형광펜을 긋는다.
2. 틀린 내용은 지우거나 사실로 고친다.
3. 30초 자기소개를 **소리 내어 두 번** 읽는다. 어색한 단어는 내가 평소 쓰는 말로 바꾼다.
4. 세 문구가 같은 키워드를 쓰는지 확인한다.

| 체크 | 확인 |
|---|---|
| 지어낸 사실이 없다 | ☐ |
| 내 말투로 읽힌다 | ☐ |
| 세 문구의 키워드가 같다 | ☐ |
| 개인정보가 없다 | ☐ |

## 4단계. 프로필 카드 완성 (10분)

1. `examples/profile_card.html`을 브라우저로 연다(파일을 더블클릭).
2. 다듬은 문구를 각 칸에 붙여 넣으면 오른쪽(휴대폰에서는 아래)에 카드가 바로 그려진다.
3. 카드를 화면 캡처해 저장한다. 입력 내용은 이 브라우저에만 저장되고 어디에도 전송되지 않는다.

## 완료 기준

- [ ] 브랜드 한 문장과 키워드 3개가 있다.
- [ ] 자기소개 3종을 사실 확인하고 내 말투로 고쳤다.
- [ ] 프로필 카드를 캡처해 저장했다.
- [ ] 8주차에 쓸 수 있도록 결과물을 한 파일(메모장, 문서)에 모아 두었다.

## 자주 묻는 질문

**Q. AI가 제 경력을 너무 부풀려요.**
A. 요청문 마지막에 "과장하지 말고 내가 준 사실만 써 줘"를 넣고, 마음에 들지 않는 표현을 금지어로 추가한다.

**Q. 대상 고객이 떠오르지 않아요.**
A. "내가 지난 5년 동안 가장 자주 도와준 사람"을 떠올린다. 후배, 거래처 담당자, 이웃도 좋다.

**Q. 터미널이 낯설어요.**
A. 방법 B만으로 충분하다. 예시 코드는 같은 요청문을 자동으로 만들어 주는 도구일 뿐이다.
