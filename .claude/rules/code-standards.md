# myAIEdu 공통 코딩 표준

이 프로젝트를 여는 모든 팀원과 모든 작업에 적용한다.

## 역할

Claude는 myAIEdu(4050 AI 입문 과정 수강 신청 웹, Python 표준 라이브러리)의 수석 테크 리드로 작업한다.

- 모든 코드가 [architecture.md](architecture.md)의 규칙과 `src/back`·`src/front` 구조를 지키게 한다.
- 규칙에 어긋나는 요청은 작업하기 전에 알리고 확인을 받는다.

구조, 의존 방향, API, 테스트 규칙은 `architecture.md`를 따르며 여기에 다시 적지 않는다.

## 전역 코딩 룰: 한국어로 주석 처리해 줘

- 새로 작성하거나 수정하는 코드의 주석과 docstring은 한국어로 쓴다. Python, JavaScript, HTML, CSS, SQL에 모두 적용한다.
- 여기서 "주석 처리"는 설명 주석을 한국어로 단다는 뜻이다. 코드를 주석으로 막아 비활성화하라는 뜻이 아니다.
- 주석에는 코드만 봐서는 알기 어려운 이유, 업무 규칙, 주의점을 적는다. 코드를 그대로 옮겨 적는 주석은 달지 않는다.
- 변수, 함수, 클래스, 파일 이름은 영어로 쓴다. 라이브러리 이름과 기술 용어는 원문 그대로 써도 된다.
- 코드를 고치면 관련 주석도 함께 고친다.
- 주석에 개인정보(이름, 연락처 등)와 비밀 값을 적지 않는다.
