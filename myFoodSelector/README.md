# 오늘 점심 뭐 먹지?

예산과 카테고리를 고르면 점심 메뉴 3개를 추천하고, 주문 기록을 남기는 배달 앱 스타일의 개인용 웹 앱입니다.

- 추천: 예산·카테고리로 거른 뒤, 최근 3일 안에 주문하지 않은 메뉴를 우선해 무작위로 3개를 고릅니다.
- 주문 히스토리: 주문한 메뉴를 날짜와 함께 저장하고, 필요하면 삭제할 수 있습니다.
- 외부 패키지가 필요 없습니다. 파이썬 표준 라이브러리만 사용하므로 `pip install` 없이 바로 실행됩니다.

---

## 1. 준비물

| 항목 | 요구 사항 |
|---|---|
| 파이썬 | 3.10 이상 (`python --version` 으로 확인) |
| 브라우저 | Chrome, Edge, Firefox, Safari 등 최신 브라우저 |
| 운영체제 | Windows, macOS, Linux 모두 동작 (Windows 기준 설명을 먼저 적었습니다) |

파이썬이 없다면 [python.org](https://www.python.org/downloads/)에서 설치합니다. Windows 설치 화면에서 **"Add python.exe to PATH"** 체크박스를 켜 두세요.

## 2. 프로젝트 구조

```
myFoodSelector/
├─ main.py            # 서버 실행 파일 (이것을 실행합니다)
├─ index.html         # 화면 (HTML + CSS + JavaScript 한 파일)
├─ data/
│  ├─ menus.json      # 메뉴 목록 (직접 수정 가능)
│  └─ history.json    # 주문 기록 (서버가 자동으로 기록·수정)
└─ README.md          # 이 문서
```

`__pycache__/` 폴더는 파이썬이 실행하며 자동으로 만드는 캐시이므로 지워도 됩니다.

## 3. 실행 방법

### 3-1. Windows (PowerShell 또는 명령 프롬프트)

```powershell
# 1) 프로젝트 폴더로 이동
cd "C:\Users\admin\OneDrive\바탕 화면\AI_myClaude\myFoodSelector"

# 2) 서버 실행
python main.py
```

아래 두 줄이 보이면 성공입니다.

```
점심 메뉴 추천 서버 실행 중: http://127.0.0.1:8000
종료하려면 Ctrl+C 를 누르세요.
```

> `python` 명령이 인식되지 않으면 `py main.py` 로 실행해 보세요. Windows의 파이썬 런처(`py`)를 쓰는 방법입니다.

### 3-2. macOS / Linux (터미널)

```bash
cd /path/to/myFoodSelector
python3 main.py
```

### 3-3. 서버 끄기

서버를 실행한 터미널 창에서 **Ctrl+C** 를 누르면 `서버를 종료합니다.` 메시지와 함께 꺼집니다.

> 서버가 켜져 있는 동안에는 그 터미널 창을 닫지 마세요. 창을 닫으면 서버도 함께 꺼집니다.

## 4. 브라우저 접속 방법

서버를 켠 상태에서 브라우저 주소창에 아래 주소를 입력합니다.

```
http://127.0.0.1:8000/
```

- `127.0.0.1` 은 **내 컴퓨터 자신**을 가리키는 주소입니다. 같은 와이파이의 휴대폰에서는 열리지 않습니다.
- 주소 끝의 `/` 는 있어도 되고 없어도 됩니다.
- `http://` 로 시작해야 합니다. `https://` 로 열면 연결되지 않습니다.
- 화면 파일(`index.html`)을 탐색기에서 더블클릭해서 열면 **동작하지 않습니다.** 반드시 위 주소로 접속하세요.

### 휴대폰에서 같은 화면 보기 (선택)

서버는 보안상 내 컴퓨터(`127.0.0.1`)에서만 접속을 받습니다. 휴대폰에서 열고 싶다면 `main.py` 의 `HOST` 를 `"0.0.0.0"` 으로 바꾸고, Windows 방화벽에서 8000 포트 접속을 허용해야 합니다. 이 앱에는 로그인 기능이 없으므로, 공용 와이파이에서는 이 설정을 쓰지 마세요.

## 5. 사용 방법

1. **카테고리 선택**: 상단의 칩(전체, 한식, 중식, 일식, 양식, 분식) 중 하나를 누릅니다. 선택된 칩은 주황색으로 표시됩니다.
2. **예산 선택**: 드롭다운에서 예산 상한을 고릅니다. "상관없음"이면 가격 제한이 없습니다.
3. **추천받기**: **메뉴 추천받기** 버튼을 누르면 조건에 맞는 메뉴 3개가 카드로 나타납니다.
   - 카드에 **최근 주문** 배지가 있으면 최근 3일 안에 먹은 메뉴입니다. 후보가 적을 때만 이런 메뉴가 나옵니다.
   - 조건에 맞는 메뉴가 하나도 없으면 "조건에 맞는 메뉴가 없어요" 안내가 나옵니다. 예산을 올리거나 카테고리를 "전체"로 바꿔 보세요.
4. **주문**: 카드 오른쪽의 **주문** 버튼을 누르면 히스토리에 기록되고, 화면 하단의 주문 건수가 바뀝니다. 그 뒤 추천 목록이 새로 고쳐집니다.
5. **히스토리 확인·삭제**: 아래쪽 **주문 히스토리**에서 최근 주문 30건까지 볼 수 있습니다. 항목의 **삭제** 버튼을 누르면 기록이 지워집니다.
6. **하단 요약**: "이번 주 주문"은 최근 7일(오늘 포함) 기준이고, "오늘"은 오늘 날짜 기준 건수입니다.

## 6. API (화면이 쓰는 주소)

화면과 같은 주소를 직접 호출해 볼 수도 있습니다. 응답은 모두 JSON입니다.

| 메서드 | 경로 | 설명 | 성공 응답 |
|---|---|---|---|
| GET | `/` | 화면(index.html) | 200 HTML |
| GET | `/api/menus` | 전체 메뉴 목록 | 200 배열 |
| GET | `/api/recommend?budget=9000&category=한식` | 추천 3개. 두 조건은 모두 선택 사항 | 200 `{"picks": [...], "recent_days": 3}` |
| GET | `/api/history` | 주문 기록 (최신순) | 200 배열 |
| POST | `/api/history` | 주문 기록 추가. 본문 `{"menu_id": 1}` | 201 기록 1건 |
| DELETE | `/api/history/{id}` | 주문 기록 삭제 | 200 `{"deleted": id}` |

### 호출 예시

Windows PowerShell에서는 `curl` 대신 `curl.exe` 를 쓰면 가장 확실합니다.

```powershell
# 메뉴 목록
curl.exe http://127.0.0.1:8000/api/menus

# 9,000원 이하 추천
curl.exe "http://127.0.0.1:8000/api/recommend?budget=9000"

# 주문 기록 추가 (메뉴 번호 1 = 김치찌개)
curl.exe -X POST http://127.0.0.1:8000/api/history -H "Content-Type: application/json" -d "{\"menu_id\": 1}"

# 주문 기록 삭제 (기록 번호 1)
curl.exe -X DELETE http://127.0.0.1:8000/api/history/1
```

> 한글 카테고리를 셸에서 직접 넣으면 인코딩 문제로 결과가 비어 나올 수 있습니다. 브라우저 화면에서는 문제없이 동작합니다. 셸에서 확인할 때는 `curl.exe -G http://127.0.0.1:8000/api/recommend --data-urlencode "category=한식"` 처럼 `--data-urlencode` 를 쓰세요.

### 오류 응답

오류는 다음 형식으로 옵니다. 화면은 `title` 과 `detail` 을 그대로 보여 줍니다.

```json
{"title": "찾을 수 없어요", "detail": "해당 메뉴를 찾을 수 없습니다."}
```

| 상황 | 상태 코드 |
|---|---|
| 예산이 숫자가 아니거나 0 이하 | 400 |
| 없는 메뉴 번호로 주문, 없는 기록 삭제, 없는 경로 | 404 |
| 요청 본문이 16KB 초과 | 413 |
| 서버 내부 오류 | 500 |

## 7. 데이터 파일

### 7-1. `data/menus.json` — 메뉴 목록

메뉴를 추가·수정하려면 이 파일을 편집하고 서버를 다시 시작하세요. 항목 하나의 형식은 다음과 같습니다.

```json
{ "id": 1, "name": "김치찌개", "category": "한식", "price": 9000, "emoji": "🍲", "eta_min": 25 }
```

| 필드 | 설명 |
|---|---|
| `id` | 고유 번호. 주문 기록이 이 번호를 참조하므로 **이미 쓰인 번호를 바꾸거나 재사용하지 마세요.** |
| `name` | 메뉴 이름 |
| `category` | 한식 / 중식 / 일식 / 양식 / 분식 중 하나 (칩 버튼과 글자가 정확히 같아야 필터됩니다) |
| `price` | 가격. 정수(원)로 쓰세요. |
| `emoji` | 카드 썸네일로 쓰는 이모지 |
| `eta_min` | 배달 예상 시간(분). 카드에 "약 N분"으로 표시됩니다. |

파일은 반드시 올바른 JSON 이어야 합니다. 쉼표 누락이나 따옴표 오류가 있으면 서버가 파일을 읽지 못해 메뉴가 비어 보입니다.

### 7-2. `data/history.json` — 주문 기록

서버가 자동으로 씁니다. 직접 편집하지 않는 것을 권장합니다.

```json
[
  { "id": 1, "menu_id": 1, "menu_name": "김치찌개", "category": "한식", "price": 9000, "date": "2026-11-18" }
]
```

- `id`: 기록 번호. 새 기록은 가장 큰 번호 + 1 로 붙습니다.
- `date`: 주문한 날짜(`YYYY-MM-DD`). 최근 주문 판정과 "오늘"·"이번 주" 집계에 쓰입니다.
- 메뉴 이름과 가격은 주문 당시 값을 복사해 저장하므로, 나중에 메뉴 가격을 바꿔도 과거 기록은 그대로 남습니다.

### 7-3. 깨진 파일 복구

JSON 형식이 깨진 파일을 읽으면 서버는 그 파일을 `.bak` 이름으로 옮기고 빈 상태로 시작합니다. 예를 들어 `history.json` 이 깨졌다면 `data/history.json.bak` 에 원본이 남아 있습니다. 필요하면 내용을 확인해 다시 복구하세요.

## 8. 설정 바꾸기

`main.py` 상단의 값을 바꾸고 서버를 다시 시작하면 적용됩니다.

| 이름 | 기본값 | 의미 |
|---|---|---|
| `PORT` | `8000` | 접속 포트. 주소도 함께 바꿔야 합니다. |
| `HOST` | `"127.0.0.1"` | 접속을 받을 주소. 내 컴퓨터만 허용하려면 그대로 두세요. |
| `RECOMMEND_COUNT` | `3` | 한 번에 추천하는 메뉴 수 |
| `RECENT_DAYS` | `3` | 이 기간 안에 주문한 메뉴는 가능하면 제외 |

## 9. 문제 해결

| 증상 | 원인과 해결 |
|---|---|
| `python` 을 찾을 수 없다고 나옴 | 파이썬이 설치되지 않았거나 PATH에 없습니다. `py main.py` 로 실행하거나 파이썬을 다시 설치하세요. |
| 서버 실행 후 `Address already in use` 오류 | 8000 포트를 다른 프로그램이 쓰고 있습니다. 이미 떠 있는 서버를 끄거나, `main.py` 의 `PORT` 를 `8001` 같은 값으로 바꾸세요. |
| 브라우저에서 "연결할 수 없음" | 서버가 꺼져 있습니다. 3장의 실행 명령을 다시 실행하세요. 주소가 `http://127.0.0.1:8000/` 인지도 확인하세요. |
| 화면은 열리는데 메뉴 카드가 비어 있음 | `data/menus.json` 형식이 깨졌을 수 있습니다. 서버 콘솔에 `[경고]` 메시지가 있는지 확인하세요. |
| 서버 콘솔에 `[경고] ... menus.json 이 없습니다` | `data/menus.json` 파일이 없습니다. 7-1절의 형식으로 파일을 만들어 주세요. |
| 추천 결과가 항상 같아 보임 | 메뉴 수가 적으면 같은 조합이 자주 나올 수 있습니다. 메뉴를 더 추가하면 다양해집니다. |
| 주문 기록이 사라짐 | `data/history.json` 이 손상되었을 수 있습니다. `data/history.json.bak` 을 확인하세요. |
| 화면을 고쳤는데 바뀌지 않음 | 브라우저 캐시 때문일 수 있습니다. `Ctrl+F5` 로 새로 고치세요. (서버는 캐시를 허용하지 않도록 설정되어 있습니다.) |

## 10. 참고

- 이 앱은 **개인용 로컬 앱**입니다. 로그인, 결제, 실제 배달 연동은 없습니다. 주문 버튼은 기록만 남깁니다.
- 메뉴 데이터는 예시이므로 실제 가게 메뉴와 다를 수 있습니다.
- 데이터는 모두 이 컴퓨터의 `data/` 폴더에 저장됩니다. 백업이 필요하면 `data/` 폴더를 복사해 두세요.
